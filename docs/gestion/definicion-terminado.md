# Definición de Terminado

Una tarea se considera terminada cuando cumple los criterios aplicables de esta lista.

## Producto

- Cumple los criterios de aceptación acordados.
- No agrega funcionalidades fuera del alcance de la tarea.
- Puede integrarse con el incremento actual.

## Código

- Sigue las convenciones del componente.
- Separa responsabilidades y evita duplicación innecesaria.
- Incluye validaciones y manejo consistente de errores.
- No contiene secretos ni información sensible.

## Calidad

- Incluye pruebas automatizadas cuando corresponde.
- Las pruebas existentes continúan funcionando.
- Fue revisado por al menos otro integrante.
- Las observaciones del pull request fueron resueltas.

## Operación y documentación

- Documenta variables de entorno nuevas.
- Incluye migraciones cuando cambia la persistencia.
- Actualiza contratos y documentación afectados.
- Puede ejecutarse siguiendo las instrucciones del repositorio.

No todos los puntos aplican a tareas exclusivamente documentales. Las excepciones deben explicarse en el pull request.
